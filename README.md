# mOSs

mOSs is a custom Linux distribution project derived from Ubuntu and inspired by Kubuntu, SteamOS, and Bazzite. The longer-term vision includes an installable system with desktop, gaming, and mobile options.

## Current status

Active implementation work is currently in [ubuntu-decK](https://github.com/KasuranCodes/ubuntu-decK). Its public code configures a SteamOS-style Game Mode session on an existing Kubuntu installation, using Steam's gamepad UI and Gamescope alongside the regular Plasma desktop session.

This repository is the broader project overview; it does not currently provide a released mOSs ISO or a working mobile variant. The planned ISO, installer, desktop distribution, and mobile options are goals rather than current features. The installer in ubuntu-decK is explicitly experimental and warns that there is no complete reversal path.
